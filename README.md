# Phishing Email Detection & Awareness System

## Project Overview

This project focuses on analyzing phishing email samples and identifying common phishing indicators used by cybercriminals.

## Objectives

* Analyze phishing email samples
* Identify phishing indicators
* Classify email risk levels
* Create phishing awareness guidelines

## Tools Used

* Google Docs
* GitHub
* Notepad
* Web Browser

## Email Samples Analyzed

* Sample 1: Account Verification Scam
* Sample 2: PayPal Security Alert
* Sample 3: Amazon Gift Card Scam

## Phishing Indicators Identified

* Generic Greetings
* Suspicious Links
* Urgency Tactics
* Fake Domains
* Reward Scams

## Risk Classification

All analyzed emails were classified as **Phishing** based on the identified indicators.

## Outcome

This project improved understanding of phishing attacks and developed awareness guidelines to help users identify and avoid phishing attempts.
